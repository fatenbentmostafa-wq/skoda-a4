# SKODA A4 - صيانة العربية

برنامج متابعة صيانة العربية: الزيت والبوجيهات وسير الكاتينة وباقي البنود.

- `index.html` - التطبيق كله
- `sw.js` - نسخة البرنامج (زوّد VERSION مع كل تعديل)
- `firebase-config.js` - إعدادات Firebase
- `firestore.rules.ADD.txt` - قواعد الأمان (تتضاف لقواعد مصاريف البيت)
- `android-app/` - تطبيق أندرويد (Capacitor)
